# Power-BI-Dashboard-project
This interactive **Power BI Dashboard** provides a complete overview of company performance using the **Sample Superstore** dataset.   It helps analyze **sales, profit, and quantity** across multiple dimensions such as region, category, and sub-category.  

## 📂 Dataset

**Dataset Name:** SampleSuperstore.csv  
**Source:** Microsoft Power BI public sample data  

The dataset includes fields such as:
- Order Date, Ship Date
- Category & Sub-Category
- Sales, Profit, Quantity
- Region, Segment, State

📁 **Path in Repo:**  
[`/data/SampleSuperstore.csv`](data/SampleSuperstore.csv)

If you don’t have this dataset, you can download it from Power BI’s official sample data library or use any public version available online.


## 📈 Dashboard Highlights
- 📅 **Sales Trend by Month & Category**
- 🌍 **Regional Performance** (West, East, Central, South)
- 💼 **Profit by Sub-Category**
- 🧾 **Sales by Category Pie Chart**
- 🪄 KPIs showing total Sales, Profit, and Quantity


## 🛠️ Tools & Technologies
- **Power BI Desktop**
- **Data Cleaning:** Power Query
- **Measures:** DAX Formulas
- **Visualizations:** Bar, Line, Pie, and Funnel Charts
